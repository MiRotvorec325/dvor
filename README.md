# Двор

Кликабельные прототипы приложения «Двор»: поиск квартиры для семьи с маленьким ребёнком при переезде в другой город.

## Открыть

- **[Прототип wireframe](https://mirotvorec325.github.io/dvor/)** — по нему проходит юзабилити-тест (`index.html`).
- **[UI-прототип](https://mirotvorec325.github.io/dvor/ui/)** — в графике UI (`ui/index.html`).

Панель модератора: [wireframe](https://mirotvorec325.github.io/dvor/#moderator) · [UI](https://mirotvorec325.github.io/dvor/ui/#moderator) (или допишите `#moderator` в конец ссылки).

Учебный проект курса «Проектирование клиентского опыта», ИТМО.
